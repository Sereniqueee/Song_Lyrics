# 🎵 Song_Lyrics

Mini project Python untuk menampilkan lirik lagu dengan efek ketikan yang menarik di terminal.

## ✨ Tentang Project

Project ini berisi dua file script Python yang menampilkan lirik lagu dengan animasi seperti sedang dinyanyikan di layar terminal. Setiap huruf muncul satu per satu dengan jeda waktu tertentu, memberi kesan lebih hidup dan interaktif.

## 🛠️ Requirement

- Python 3.x
- Terminal/Command Prompt yang mendukung warna ANSI

## 💡 Fitur

- Animasi teks seperti karaoke di terminal
- Tampilan bersih dan simpel

## 🚀 Tujuan

Project ini cocok untuk belajar:

- Python dasar
- Threading
- Animasi output terminal
- Struktur project sederhana

Semoga project ini bermanfaat dan membuat belajar Python lebih menyenangkan!
